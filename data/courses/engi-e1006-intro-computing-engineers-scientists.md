## Why This Course Matters

The Python substrate under the whole computational half of this plan. Every tool the
target work runs on is Python: RDKit, PyTorch, OpenMM, PySCF, the molecular ML stack
entirely.

Registrar description: *"An interdisciplinary course in computing intended for first year
SEAS students. Introduces computational thinking, algorithmic problem solving and Python
programming with applications in science and engineering. Assumes no prior programming
background."*

Chosen over COMS W2132 (Intermediate Computing in Python) for one reason only: **W2132 is
spring-only**, verified against the registrar, so it cannot sit in Semester III. Chosen
over COMS W1002 (Computing in Context) because the "computational thinking and algorithmic
problem solving" framing is the better bridge into APMA E4300, where the Python work is
numerical — W1002's Computing in Biology track leans toward data handling and sequence
work, which is further from molecular simulation than its title suggests. Credit can be
received for only one of ENGI E1006 or COMS W1002.

Placed in Semester III so Python is in hand a full semester before APMA E4300 (Semester
IV), where every topic is "programmed in Python." That ordering is the point: E4300 assumes
Python and teaches numerical methods, so Python has to arrive first.

**Caveat — registration risk.** Fall 2026 ran 292 of 300 seats filled, with a note that
the class is prioritised for SEAS until later in summer. As a College student, expect to
register behind SEAS for the remaining seats. Spring sections are far emptier (Spring 2027
opened at 0 of 189), so the spring offering is the fallback if the fall seat does not come
through.

**Level note.** The course assumes no prior programming, and the docking project already
runs RDKit pipelines. Expect the first weeks to be review; the value is the back half plus
having the prerequisite formally on the transcript.

**Logistics:** 3pt, standard grading, in person, no approvals required. Instructor Chris
Murphy in Fall 2026. Offered both fall and spring.
