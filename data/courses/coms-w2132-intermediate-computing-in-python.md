## Why This Course Matters

Essential data structures and algorithms in Python, with practical software development
skills — the catalog lists applications in biology, natural language processing and data
science.

The substrate under the whole computational half of this plan. Every tool the target work
runs on is Python: RDKit, PyTorch, OpenMM, PySCF, the molecular ML stack entirely. This is
also the course that makes the rest of the ML additions usable rather than theoretical, so
it goes first in the sequence.

Replaces COMS W1004 (Programming in Java) and COMS W3134 (Data Structures in Java), both
cut on 2026-09-05. One course instead of two, and in the right language — the Java track
taught the concepts in a language nothing downstream uses.

**Prerequisite note:** COMS W4771 lists algorithm analysis (W3134) among its
prerequisites, which this covers in substance even where the registrar wants the Java
course.
